# 설정 바꾸기

[README로 돌아가기](../../README.md)

## 설정 바꾸기

```text
/subagent-workflow:setting
```

설치한 뒤에 워크플로 설정을 보고 바꾸는 스킬이에요.

- **지금 설정 보기**: 워크플로가 쓸 수 있는 선택 MCP 목록과 선택 여부(용도와 주의 사항 포함)를 보여 줘요. 이 목록은 Claude Code의 `/mcp`와 달라요. `/mcp`는 연결된 모든 서버를 보여 주고, 여기서는 워크플로가 쓰는 서버만 골라서 보여 줘요.
- 기본 모드(Lite, Full)와 보호 모드(권고, 엄격) 선택은 v0.7.0에서 없앴어요. 워크플로는 한 가지 경로로 동작하고 가드는 항상 켜져 있어요.
- **MCP 추가, 해제**: 설치할 때 고르지 않았던 MCP(anymd, Playwright, Chrome DevTools, shadcn/ui, Figma)를 여기서 고르면 `.mcp.json`에 등록하고, 디자인 도구는 해제하거나 Figma 연결 방식을 바꿀 수도 있어요(Context7과 Jina는 플러그인에 들어 있어 여기서 고르지 않아요. 끄려면 `/mcp`를 써요). 워크플로가 등록하지 않았거나 설치 뒤 바꾼 항목은 지우지 않아요. 새 Claude Code 세션을 시작해야 적용돼요.
- 바꾸기 전에 미리보기를 보여 드리고, 확인한 뒤에만 적용해요. 바꾸기 전 파일은 백업해요.
- 이미 다른 설정이 있는 MCP는 덮어쓰지 않고 충돌로 알려 드려요.
