## 판단 대상

워크플로의 가치는 어려운 과제(l1 숨은 호출처, m1 암묵 요구, l2)에서만 판단함
쉬운 과제(s1·s2·x1·m2·m3)는 워크플로에 맡길 요청이 아니므로 비용 수치를 워크플로의 효용 근거로 쓰지 않으며, 불필요하게 워크플로를 부르지 않는지 확인하는 용도로만 기록함
어려운 과제의 워크플로 조건 측정은 l1 6회(개선 전 Lite 1, 개선 후 Lite 4·Full 1, 이 중 1회는 중단), m1 4회, l2는 직접 처리 1회뿐이고 조건별 반복이 1회라 설계 기준으로 판정할 수 없음

## 개선 내용: L2 직접 경로

PM 지침에 L2 직접 경로 추가(PR #33), 위험 신호(L3 기준, 변경 심볼의 외부 사용처, 해석 둘 이상 또는 암묵 요구 후보, 세 개 이상 파일·기존 테스트 수정, 승인 항목·엄격 모드)가 없으면 위임·기획 파일 없이 처리
L3는 직접 경로 대상이 아님을 명시(PR #34~#36), 설계 문서 변경 이력에 데이터를 본 뒤의 보정임을 기록

## 한계 (공개)

- **L3 절차 준수는 지침에만 의존하며 강제되지 않음**: Lite l1에서 PM이 L3로 분류하고도 계획서·architecture 조사·사용자 확인 없이 직접 수정했고, 이 상황이 지침 보강 후에도 반복됨, 개선 전에는 같은 조건에서 위임 5회를 했음
- 이 위반이 호출처 파손으로 이어진 것은 4회 중 1회이며 위반이 곧 품질 하락이라는 증거도, 안전하다는 증거도 아님
- 대화형 사용에서 L3 확인 대화가 지켜지는지는 이 평가로 확인하지 못함(비대화형 실행)
- 과제는 작은 합성 fixture, 반복 1회, 한 모델이라 일반화 금지
- Full의 l1은 개선 후 1회만 측정, 개선 전 Full l1은 미실행이라 전후 비교 불가
- 직접 경로의 점검 결과는 실행기 기록이 없고(`unrecorded`) 독립 QA도 없음
- 분류 일치(D1) 기준은 데이터를 본 뒤 m2·m3에 한해 완화
