# 검증 기록 목차

이 저장소가 어떤 시험을 했고 어떤 결과가 나왔는지 시험 종류별로 모은 곳
릴리즈 버전이 아니라 "무엇을 확인했는가"를 기준으로 정리했고, 같은 시험을 다시 하면 새 회차를 같은 문서에 추가함
모든 기록에는 측정 조건, 측정일, 대상 커밋, 확인하지 못한 것이 함께 적혀 있음
정적 검사와 단위 테스트의 통과는 실제 Claude의 행동을 입증하지 않으므로 실제 Claude 실행 결과와 구분해 적음

## 시험 목록

## 아직 확인하지 못한 것

1. 대화형 화면(스킬 실행 허용 창, 신뢰 화면)과 L3의 사용자 확인 질문이 실제로 나오는지
2. macOS와 Linux에서의 실제 Claude 실행(단위 테스트와 CI는 ubuntu와 windows)
3. PM이 직접 고치려다 가드에 막히는 장면(단위 테스트로만 확인)
4. 수정한 L3 기준이 쉬운 과제를 L3로 잘못 올리지 않는지
5. 여러 모델, 여러 프로젝트에서의 재현(지금은 한 모델과 작은 합성 fixture)
6. 엄격 모드의 대화형 승인 흐름
7. 과제당 3회 이상의 반복(대부분 1~3회라 통계적 유의성을 주장하지 않음)
