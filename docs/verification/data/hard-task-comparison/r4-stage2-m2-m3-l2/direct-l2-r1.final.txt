사용자에게 선택 항목 `phone`을 추가했고, `npm test`는 5개 모두 통과했습니다. 새로 추가한 API 테스트만 확인했습니다. 카드와 CSV 변경은 실행해서 확인하지 않았습니다.

- **`src/users.js`**: `makeUser`가 `phone`을 받습니다. 값이 있을 때만 객체에 `phone` 키를 넣습니다.
- **`src/api/user-api.js`**: `phone`이 있을 때만 응답에 `phone` 키가 들어갑니다. 없으면 키 자체가 없습니다.
- **`src/ui/user-card.js`**: `phone`이 있으면 `이름 <이메일> · 전화번호` 형식으로 나옵니다. 없으면 기존 `이름 <이메일>` 그대로입니다.
- **`src/export/user-export.js`**: CSV 끝에 전화번호 열이 붙고, 없으면 빈 칸입니다. 전화번호가 없으면 줄이 `1,Ann,ann@x.io,`처럼 쉼표로 끝납니다.
- **`test/user-api.test.js`**: phone이 있을 때와 없을 때를 확인하는 테스트를 추가했습니다. 기존 테스트는 그대로 두었습니다.

**제가 판단한 부분**
- 빈 문자열 `""`도 "없음"으로 보고 키를 생략합니다.
- 카드에서 phone이 없을 때는 끝에 ` · `를 붙이지 않습니다.
- `scripts/export-csv.js`는 사용자가 아니라 상품 항목용이라 건드리지 않았습니다.
- 전화번호 형식 검증이나 CSV 이스케이프는 요청에 없어서 넣지 않았습니다.
- `dist/`와 `config/`는 수정하지 않았습니다.
