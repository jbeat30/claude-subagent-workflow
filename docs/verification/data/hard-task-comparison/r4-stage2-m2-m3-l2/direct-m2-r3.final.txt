`npm test`가 이제 모두 통과합니다(5개 통과, 0개 실패).

**원인:** `src/discount.js`의 `percentOff`가 `Math.floor(total * (100 - pct) / 100)`으로 계산해서 결과를 정수로 내림했습니다. 그래서 `percentOff(19.99, 10)`이 17.99가 아니라 17이 나왔습니다.

**수정:** 정수 단위로 내림하는 대신, 곱한 값을 반올림한 뒤 100으로 나눠 센트 단위를 유지하도록 바꿨습니다.
```js
return Math.round(total * (100 - pct)) / 100;
```

**판단한 내용:**
- 테스트는 수정하지 않았습니다. 기대값 17.99가 "센트 유지"라는 테스트 이름과 맞아서, 틀린 쪽은 구현이라고 봤습니다.
- 센트 미만은 내림이 아니라 반올림으로 처리했습니다. 반올림 규칙에 대한 명세는 없었고, 반올림이 일반적인 금액 계산 방식이라 이쪽을 택했습니다.
- `percentOff`를 쓰는 곳은 `src` 안에 이 함수 정의뿐이라 다른 코드에 미치는 영향은 없습니다.
- `dist/`와 `config/`는 건드리지 않았습니다.
