discount 테스트 실패를 고쳤고, 이제 `npm test` 5개가 모두 통과합니다.

**원인:** `src/discount.js`의 `percentOff`가 `Math.floor`로 결과를 정수로 내려서 센트가 사라졌습니다. 19.99에 10%를 적용하면 17.99가 나와야 하는데 17이 나왔습니다.

**수정:** `src/discount.js` 한 파일만 바꿨습니다. `Math.round(total * (100 - pct)) / 100`으로 소수 둘째 자리까지 반올림합니다. 200에 10% 할인은 그대로 180입니다.

**확인:**
- `npm test`는 종료 코드 0이고 5/5 통과입니다.
- QA 검증에서도 실패 항목이 없었고, 변경 파일은 `src/discount.js` 하나뿐입니다.
- 테스트 파일, `dist/`, `config/`는 건드리지 않았습니다.

**자동 실행이라 제가 판단한 내용:**
- 요청을 L2(한 파일 내부 로직 수정)로 분류했습니다. `percentOff`를 쓰는 곳은 테스트뿐이어서 호출부 영향은 없다고 봤습니다.
- 테스트의 기대값(17.99)이 맞다고 보고 테스트는 고치지 않았습니다.
- 소수 둘째 자리 반올림을 택한 건 테스트가 센트를 기대해서입니다. `Math.floor`를 소수 둘째 자리에서 내림하는 방식도 가능하지만, 부동소수점 오차 위험이 있어 반올림으로 했습니다. 원래 내림 의도였다면 알려주세요.
- 사용자 승인이 필요한 항목은 없어서 계획은 PM이 자체 확인했습니다.

**미검증:**
- 반올림이 갈리는 경계값(0.5센트 단위) 입력은 테스트가 없어 확인하지 못했습니다.
- QA 에이전트는 계획 파일 해시를 직접 비교하지 못했습니다. 다만 `verify`와 `trace`는 모두 ok였습니다.
